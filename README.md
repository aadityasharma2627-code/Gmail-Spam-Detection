# 📧Gmail Spam Detection System

An AI-powered Gmail Spam Detection System that securely connects to a user's Gmail account using the Gmail API, fetches recent emails, and classifies them as **Spam** or **Ham** using a Machine Learning model.

Unlike traditional spam detection systems where users manually paste email text, this application automatically scans emails directly from Gmail and predicts whether they are spam while also providing a confidence score.

---

## 🚀 Features

- 🔐 Secure Gmail OAuth Authentication
- 📥 Fetch latest emails directly from Gmail
- 📨 Analyze both Subject and Email Body
- 🤖 Machine Learning-based Spam Detection
- 📊 Confidence Score for every prediction
- ✍ Manual Email Prediction
- 🔍 Search scanned emails by subject
- 🌙 Dark/Light Theme Support
- ⚡ Scan up to 100 recent Gmail emails
- 🖥 User-friendly Flask Dashboard

# 🧠 Machine Learning Model

The spam detection model uses:

- TF-IDF Vectorization
- Random Forest

The model is trained on a labeled Spam/Ham email dataset and predicts whether an email is Spam or Ham along with a confidence score.

# 🔑 Gmail API Setup

This repository **does not include Google OAuth credentials** for security reasons.

You must create your own Google Cloud Project.

### Step 1

Go to

https://console.cloud.google.com/

---

### Step 2

Create a new Google Cloud Project.

---

### Step 3

Enable the Gmail API.

```
APIs & Services
        ↓
Library
        ↓
Search "Gmail API"
        ↓
Enable
```

---

### Step 4

Configure the OAuth Consent Screen.

---

### Step 5

Create an OAuth Client ID.

```
Credentials
        ↓
Create Credentials
        ↓
OAuth Client ID
```

---

### Step 6

Download the credentials file.

Rename it as

```
credentials.json
```

and place it inside the project root.

---
### Step 7
Dataset

The original dataset used to train this project is not included in this repository because of its large size.

Download it from:

**Dataset Link:** https://www.kaggle.com/datasets/nikhilchaudhary7108/spam-email-datasetenron-trec-and-others?select=email_dataset_classification.csv

After downloading, place the files inside the `dataset/` folder:

```
dataset/
└── email_dataset_classification.csv
```

### Step 8

Train the Model

Before running the application, train the model by executing:

```bash
python train_model.py
```
This will automatically generate:

model/spam_model.pkl
model/tfidf_vectorizer.pkl
---

### Step 9

Run the application.

```bash
python app.py
```

The browser will automatically ask for Gmail authorization during the first run.
